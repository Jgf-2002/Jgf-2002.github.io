# 贾格非 · Personal Resume

个人履历与研究作品集初版，视觉采用“专业履历主页 + 架构师白板草图”的组合方式。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 内容更新

- 页面内容：`app/page.tsx`
- 全局样式：`app/globals.css`
- 头像：`public/profile.jpg`

所有流程图均为页面内可编辑 SVG，中文使用真实文本，不依赖位图中的文字。

## GitHub Pages

仓库内已准备手动触发的 Pages 发布流程。确认公开信息范围后，将仓库设为公开、启用 GitHub Pages，再运行 `Deploy GitHub Pages` 即可发布。
